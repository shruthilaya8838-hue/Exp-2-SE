# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:

To design a UML model for the Library Management System using StarUML

# SRS (Procedure):
1. Open the StarUML application on the computer.

2. Create a new project by selecting UML Project.

3. Select Use Case Diagram from the Model Explorer.

4. Identify the main actors: Admin, Librarian and Student.
